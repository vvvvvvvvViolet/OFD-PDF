# OFD → PDF Converter

โปรแกรม Windows สำหรับแปลงไฟล์ OFD เป็น PDF — ไม่ต้องติดตั้ง แตก zip แล้วเปิด `OfdToPdf.exe` ได้เลย

**ดาวน์โหลด:** หน้า [Releases](../../releases) → `OfdToPdf-windows.zip`

## ใช้งาน
1. เพิ่มไฟล์ `.ofd` — ลากมาวาง, กด **เพิ่มไฟล์** (Ctrl+O) หรือ **เพิ่มโฟลเดอร์** (Ctrl+Shift+O, รวมโฟลเดอร์ย่อย)
2. เลือกที่เก็บ PDF (ข้างไฟล์ต้นฉบับ หรือโฟลเดอร์ที่เลือก) และวิธีจัดการไฟล์ชื่อซ้ำ: สร้างชื่อใหม่ / เขียนทับ / ข้าม
3. กด **แปลงเป็น PDF** (F5)
4. ดับเบิลคลิกแถวที่สำเร็จเพื่อเปิด PDF, คลิกขวาเพื่อ แสดงในโฟลเดอร์ / แปลงซ้ำ / คัดลอกรายละเอียด

รายการไฟล์แสดงจำนวนหน้า สถานะ และคำเตือนก่อนแปลง (ไฟล์เสีย, เกิน 3 หน้า, มีลายเซ็นดิจิทัล)
หลังแปลงจะตรวจจำนวนหน้าของ PDF เทียบกับต้นฉบับ — ถ้าไม่ครบจะขึ้นสถานะ **⚠ ไม่ครบ**
การตั้งค่าจะถูกจำไว้สำหรับครั้งถัดไป

**คลิกขวาใน Explorer:** เมนู เครื่องมือ → เพิ่มในเมนู "ส่งไปยัง" แล้วคลิกขวาที่ไฟล์/โฟลเดอร์ → ส่งไปยัง → *แปลง OFD เป็น PDF*
(ลากไฟล์ไปวางบน `OfdToPdf.exe` ก็ได้ผลเหมือนกัน — หน้าต่างจะเปิดและแปลงให้ทันที)

### Command line
```
OfdToPdf.exe <ไฟล์หรือโฟลเดอร์>... [-o <โฟลเดอร์>] [--overwrite | --skip-existing] [--cli]
OfdToPdf.exe --help
```
exit code `0` = สำเร็จทั้งหมด, `1` = มีไฟล์ล้มเหลว, `2` = ตัวเลือกผิด
(เมื่อเรียกจาก terminal จะทำงานแบบ command line; `--cli` บังคับโหมดนี้เสมอ เช่นในสคริปต์)

## ตัวอักษรเพี้ยน / ฟอนต์
ไฟล์ OFD มักใช้ฟอนต์จีนที่ไม่ได้ฝังมาในไฟล์ (เช่น 黑体, 楷体) โปรแกรมจะ **แทนด้วยฟอนต์ที่มีในเครื่องให้อัตโนมัติ**
(เช่น 黑体 → Microsoft YaHei) และบอกในช่องรายละเอียด ถ้าต้องการหน้าตาตรงต้นฉบับ:

1. ติดตั้ง *Chinese (Simplified) Supplemental Fonts* (Settings → Apps → Optional features) หรือ
2. คัดลอกไฟล์ฟอนต์ (.ttf/.ttc/.otf) ไปไว้ใน เครื่องมือ → เปิดโฟลเดอร์ฟอนต์เพิ่มเติม แล้วแปลงใหม่ (ไม่ต้องปิดโปรแกรม)

## ข้อควรรู้
- ใช้ Free Spire.PDF (รุ่นฟรีของ e-iceblue): **ไม่มี watermark** แต่แปลงไฟล์ OFD ได้ **เฉพาะ 3 หน้าแรก** (ทดสอบจริงใน CI: OFD 12 หน้า → PDF 3 หน้า)
  โปรแกรมเตือนก่อนแปลงและตรวจผลหลังแปลง; เอกสารที่ยาวกว่านั้นต้องใช้ Spire.PDF แบบมี license หรือเปลี่ยน engine ใน `src/OfdToPdf/Converter.cs`
- ไฟล์ OFD ที่มี **ลายเซ็นดิจิทัล**: PDF ที่ได้เป็นสำเนาสำหรับอ่าน ลายเซ็นไม่ได้ถูกตรวจหรือคงไว้ — เก็บไฟล์ OFD ต้นฉบับไว้เป็นหลักฐาน
- การตั้งค่า ฟอนต์เพิ่มเติม และบันทึกการทำงาน (log) เก็บในเครื่องที่ `%LocalAppData%\OfdToPdf`
- ตัว exe ไม่ได้ลงลายเซ็น (code signing) — Windows SmartScreen อาจเตือนครั้งแรก: More info → Run anyway

## พัฒนา
```
dotnet build src/OfdToPdf/OfdToPdf.csproj -c Release -o out
```
ต้องใช้ Windows + .NET SDK; ผลลัพธ์ `out\OfdToPdf.exe` (รันบน .NET Framework 4.8 ที่มีใน Windows 10/11)

GitHub Actions build และทดสอบทุก push (ฟอนต์ไม่เป็นกล่อง, ไม่มี watermark, การจัดการไฟล์ชื่อซ้ำ, ไฟล์เสีย, ขีดจำกัดหน้า, ภาพหน้าจอ UI)
ออก Release: แท็บ Actions → *Build EXE* → *Run workflow* → ใส่ `release_tag` เช่น `v1.1`
